# Paper: Who Rewrites the Loop?

ACM `sigconf` two-column paper on human versus agent authorship in the recursive self-improvement of open-source agent harnesses.

## Files

- `main.tex` — ACM two-column source (review mode with line numbers)
- `main.pdf` — compiled 10-page PDF
- `acmart.cls` — the ACM class (TeX Live in this environment does not ship it; the class is vendored here)
- `make_figures.py` — regenerates the three vector figures from `../reports/tables/`
- `figures/*.pdf` — vector figures used in the paper (PNG copies are for preview only)

## Build

```bash
latexmk -pdf main.tex
```

or run `pdflatex main.tex` twice. The paper uses `acmart`, `booktabs`, `array`, `microtype`, `hyperref`, and `url`, all present in a standard TeX Live. No BibTeX run is needed; references are in a `thebibliography` block.

All three figures are PDF vector graphics generated by `make_figures.py` with `pdf.fonttype=42`. Re-run it after any analysis change:

```bash
python3 make_figures.py
```

## Reproducibility

Numbers in the text trace to `../reports/summary.json` and `../reports/tables/`. The human-review package is in `../review_package/`; `review.html` is self-contained and can be used without the CSV files.
